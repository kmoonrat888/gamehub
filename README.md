# บ้านเกมเรียนรู้ (React + Vite)

เว็บรวมเกมฝึกคณิตศาสตร์และภาษาอังกฤษสำหรับเด็ก

## คำสั่ง
```bash
npm install      # ติดตั้งครั้งแรก
npm run dev      # เปิดดูในเครื่อง http://localhost:5173
npm run build    # สร้างเว็บพร้อมอัปขึ้นโฮสต์ ไว้ในโฟลเดอร์ dist/
npm run preview  # ทดลองเปิดเว็บที่ build แล้ว
```
### เปิดให้อุปกรณ์อื่นในวง Wi-Fi เดียวกันเข้าเล่น (Private IP)
```bash
npm run dev:lan      # โหมดแก้ไข เปิดให้เครื่องอื่นเข้าได้
npm run preview:lan  # เว็บที่ build แล้ว เปิดให้เครื่องอื่นเข้าได้
```
ดูบรรทัด `Network: http://192.168.x.x:port/` ในหน้าจอ แล้วเปิดที่อยู่นั้นจากมือถือ/แท็บเล็ต
ครั้งแรก Windows จะถามเรื่องไฟร์วอลล์ ให้กด **Allow** สำหรับเครือข่ายแบบ Private

เว็บที่ build แล้วต้องเปิดผ่านเซิร์ฟเวอร์ (`npm run preview` หรือโฮสต์ เช่น Netlify / GitHub Pages / Vercel)
ดับเบิลคลิก `dist/index.html` ตรง ๆ จะไม่ทำงาน

## เพิ่มเกมใหม่
1. วางไฟล์เกม (HTML ไฟล์เดียว) ไว้ใน `public/games/`
2. (ไม่บังคับ) วางรูปตัวอย่างขนาด 800×500 ไว้ใน `public/thumbs/`
3. เพิ่ม 1 รายการใน `src/data/games.js`

## โครงสร้าง
- `src/pages/Home.jsx` — หน้ารวมเกม (ค้นหา, กรองหมวด, เล่นล่าสุด)
- `src/pages/Play.jsx` — หน้าเล่นเกม (แสดงเกมใน iframe, ปุ่มเต็มจอ/แท็บใหม่)
- `src/data/games.js` — ข้อมูลเกมทั้งหมด
- `public/games/` — ไฟล์เกม (สำเนาจากโฟลเดอร์หลัก ถ้าแก้เกม ให้แก้ไฟล์ในนี้)
